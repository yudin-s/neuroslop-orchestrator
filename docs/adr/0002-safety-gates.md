# ADR-0002: Tool and patch safety gates

- **Status:** Accepted
- **Date:** 2026-02-26

## Context
LLM-агенты могут генерировать команды и патчи, что потенциально опасно для локальной среды разработки.

## Decision
Вводятся обязательные safety-gates:
- allowlist для shell-команд;
- denylist/allowlist для чтения файлов;
- ограничения web-доступа по доменам;
- проверка `git apply --check` перед применением патча;
- интерактивное подтверждение в режиме `approval=interactive`.

## Consequences
### Positive
- Снижение риска случайного вредоносного или некорректного действия.
- Контролируемый и воспроизводимый процесс изменений.

### Trade-offs
- Часть легитимных операций может требовать расширения allowlist.
- Дополнительная сложность в конфигурации `config.yaml`.
